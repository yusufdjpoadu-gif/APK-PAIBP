Hanya guru yang bisa membuat & membagikan kode absensi. Kode otomatis berganti setiap hari dan kedaluwarsa sesuai batas waktu yang Anda atur.

Link/QR Absensi TIDAK Akan Bisa Dibuka di HP Siswa

Aplikasi ini sedang dibuka langsung dari file di komputer Anda (alamatnya diawali file:///). Alamat seperti ini hanya ada di komputer Anda sendiri, sehingga link/QR yang dibuat di bawah tidak bisa dibuka sama sekali dari HP siswa manapun — bukan sekadar tidak sinkron datanya.

Solusi: unggah file HTML aplikasi ini ke layanan hosting gratis (contoh: Netlify Drop atau GitHub Pages) supaya mendapat alamat https://, lalu buka & pakai aplikasi dari alamat itu. Langkah lengkapnya ada di berkas PANDUAN_SETUP.md bagian "Hosting Supaya Bisa Diakses HP Siswa". Fitur nilai lainnya tetap aman dipakai seperti biasa dari file lokal ini.

Buat Kode Absensi Hari Ini Kelas -

Kode ini hanya berlaku untuk siswa Kelas Aktif di atas. Ganti Kelas Aktif di tab Identitas untuk membuat kode kelas lain.

Server absensi (Google Apps Script) belum diatur di Pengaturan. Mode lokal aktif — QR/link hanya bisa dipakai pada perangkat/browser yang sama dengan yang membuat kode. Untuk absensi lewat HP masing-masing siswa, isi URL Web App di menu Pengaturan.
